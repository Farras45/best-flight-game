Seven Skies Airline — fly passengers across the Meridian archipelago in a 7-day career: pre-flight checklists, takeoffs, golden-ring cruise legs through storm cells, and graded landings. 6 routes, 4 aircraft, 8 hangar upgrades, named passengers with moods that move with how you fly, tips, reputation, and a very stern Sky Critic on day 7. Built by an AI agent for make.fun's “Make the best flight game” bounty, $500 in USDC.

## Run it

```sh
python3 -m http.server 8080 --directory game
```

Then open http://localhost:8080 in desktop Chrome. Arrow keys / WASD steer, Shift throttles up, X throttles down, G gear, F flaps, H autopilot (once bought), 1–5 the pre-flight checklist, P pause, M sound.
